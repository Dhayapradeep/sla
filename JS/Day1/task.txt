1. What is JavaScript?

JavaScript is a programming language used to make web pages interactive and dynamic. It can be used for things like buttons, animations, form validation, calculations, and web applications.

2. What is a variable?

A variable is a named storage location used to store data in a program. For example, userName can store a person's name.

let userName = "Dhayapradeep";

3. What is variable declaration?

Variable declaration means creating a variable by specifying its name using var, let, or const.

let userName;

Here, userName is declared but no value has been given yet.

4. What is initialization?

Initialization means giving an initial value to a variable when it is created.

let age = 21;

Here, age is declared and initialized with the value 21.

5. What is an assignment operator?

The assignment operator = is used to assign a value to a variable.

let age;
age = 21;

Here, = assigns 21 to age.

6. What are var, let and const?

var, let, and const are JavaScript keywords used to declare variables.

var city = "Chennai";
let age = 21;
const country = "India";

7. What is the difference between var, let and const?
Feature			var	let	const
Redeclaration		Yes	No	No
Reassignment		Yes	Yes	No
Scope			Function	Block	Block
Must initialize		No	No	Yes

Example:

var age = 20;
age = 21;


let score = 50;
score = 60;


const pi = 3.14;

const cannot be reassigned after initialization.

8. What is ES6?

ES6 stands for ECMAScript 2015. It is a major version of JavaScript that introduced features such as let, const, arrow functions, classes, template literals, and destructuring.

9. What is a JavaScript Engine?

A JavaScript Engine is a program that reads, processes, and executes JavaScript code. Different browsers use different JavaScript engines.

Examples include V8, SpiderMonkey, and JavaScriptCore.

10. What is V8?

V8 is a JavaScript engine developed by Google. It is used in Google Chrome and also powers JavaScript execution in environments such as Node.js.
